Texts: COPYING3 and COPYING.RUNTIME, from the GCC source tree.
Upstream: https://gcc.gnu.org/

Linux: libzonos3_c.so is built with GCC 14 from AlmaLinux 8's gcc-toolset-14,
which links the parts of libstdc++ newer than the system's GCC 8, and libgcc,
into the library itself; and libgcc_s.so.1, from AlmaLinux 8's GCC 8, ships
beside zyphra-textnorm's Rust extension, which links it for unwinding. On
macOS and Windows libzonos3_c is built with Apple's and Microsoft's compilers
and carries no GCC code.

The GCC Runtime Library Exception lets these libraries travel with a program
under another licence without the program becoming GPL. No source offer is
needed for the runtime libraries themselves.
